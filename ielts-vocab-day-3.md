## 1. robust

| Field | Content |
|---|---|
| **IPA** | UK /rəʊbʌst/ · US /roʊbʌst/ |
| **Chinese** | 强健的 (健康); 稳固的 (经济/系统); 结实的 (物体) |
| **Root & Affix** | 拉丁语 *robustus* = "oaken, strong"，来自 *robur* = "oak tree" → 像橡树一样结实 |
| **Word Forms** | adj. robust · adv. robustly · n. robustness |
| **Synonyms** | sturdy, vigorous, resilient, hardy · **Antonyms**: fragile, delicate, vulnerable, weak |
| **Examples** | 📖 Academic: *"The eurozone showed a surprisingly robust economic recovery following the 2022 energy crisis."* <br> 💬 Oral: *"My grandma is still so robust — she goes hiking every weekend at 78!"* |
| **Memory Tip** | *Rob* (橡树) + *ust* → 橡树橡木做的东西 = robust; 对比 *resilient* (Day 1 弹性的); *robustness* 是金融风控里的稳健性指标 |
| **Collocations** | robust economy / health / system / evidence · robust growth · a robust defence · robustly built |
